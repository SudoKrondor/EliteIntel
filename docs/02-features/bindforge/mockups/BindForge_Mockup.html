The ASSISTANT column on the right answers one question: can EliteIntel drive this control? Blank is the common case. NOT BOUND and CAN'T PRESS are the two shapes of Missing — nothing assigned, or assigned only to a device EliteIntel cannot send input to. ON PURPOSE is the commander saying stop reporting this; it silences both, and the control stays bound to whatever it was. Hover a mark for the reason. Hover a row to reveal Capture buttons per slot (light blue = empty, green = bound, red = conflicting). Capture is the only way in — clicking a row never opens anything, so a stray click cannot start a rebind. It opens one capture dialog, Krondor's existing assign dialog grown: titled with the in-game name, with tabs for KEYBOARD, MOUSE and every connected controller. Tabs that cannot fill the slot are greyed out — an axis row enables only a controller's AXES; a button row enables everything else. Controller tabs split into BUTTONS · HATS · AXIS DIRECTIONS · AXES, labelled from each device's .buttonMap. Axis rows add Inverted and Deadzone (still inline on the row). Hold Ctrl/Shift/Alt while clicking for a combo across devices. SAVE writes to the draft; BACK or Esc cancels. C, A and D show the conflict warning.
