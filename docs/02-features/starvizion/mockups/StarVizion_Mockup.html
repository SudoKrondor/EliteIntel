MODE-BASED SWITCHING
Switching
While assigned, this HoloFrame's own switching governs every member Vizlet's visibility — each member's individual Mode-Based Visibility setting is not consulted while it belongs to this HoloFrame. Manual activate/deactivate always remains available too.
RENDER MODE OVERRIDE
Override
When set, every member Vizlet renders using this mode instead of its own individually-configured Render Mode. This is whole-group only — split members across separate HoloFrames to get mixed render behavior.
