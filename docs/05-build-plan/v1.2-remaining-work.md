# BindForge V1.2 — what is left

**Rewritten 2026-11-10, checked against `V1.2` at `127ba2940`** (and the label rename made the same day, not yet
committed). It replaces the 2026-11-03 snapshot, whose lanes, percentages and decision table no longer applied. It is
a snapshot, not a tracker: slice status stays in each section's brief, and this page goes stale the same way.

**StarVizion is V2.0, not V1.2** (Krondor, 2026-11-10), and is not counted here.

## Settled since 2026-11-03

- **The Bind Editor screen is final for V1.2** (Krondor, 2026-11-10). One tab row - All, General, Ship, SRV, On-Foot,
  then Anomalies and Dead Zones & Sensitivity - over one grid (Krondor and Alan, 2026-11-06). There is no Game Mode tab;
  the section tabs are Game Mode. [Bind Editor](../02-features/bindforge/bind-editor.md)
- **Rejected for V1.2** (Krondor, 2026-11-10):
  - **E6** - no settings rows, booleans or dropdowns in the grid. Dead Zones & Sensitivity keeps its number rows.
  - **GM1** - no collapsing groups, section filter bar, Esc to clear the search or slot-cell conflict colour. The
    grid built 2026-11-06 is the different, simpler design.
  - Already dropped 2026-11-03: AN2, AN4, AN5 and Anomalies' Reserved, Missing and Invalid sub-tabs.
- **The Preset Editor is a section inside Binding Management**, not a sub-tab (Krondor, 2026-11-10): more room, and
  the more logical place. It can move later.
- **Labels:** the main tab is **BindForge** and Binding Profile is **Bind Editor**, in all nine bundles, done
  2026-11-10 with the strings that name them (the spoken conflict warnings, the folder warnings, the LOAD tooltip,
  CREATE's no-factory message). **Binding Management keeps its name**; the docs still call that section File Manager.
