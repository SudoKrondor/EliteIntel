Installation

Elite Intel V1.1 ist die aktuelle Version.

Linux Windows

  1. Den 👉Installer👈 herunterladen.
  2. Den Installer ausführen und den Anweisungen auf dem Bildschirm folgen.
  3. Ein LLM einrichten. Ohne LLM läuft Elite Intel nicht. Zwei Optionen stehen zur Verfügung:
    • Lokales LLM (kostenlos, offline): Siehe die Lokale LLM-Anleitung. Erfordert leistungsfähige GPU-Hardware.
    • Cloud-LLM (hat eine kostenlose Option und ist einfacher einzurichten): Siehe Cloud-LLM-Optionen, um einen API-Schlüssel zu bekommen, und trage ihn dann unter Einstellungen → KI-Dienste ein. Kostenloser Tarif, ohne Kreditkarte: 👉 console.mistral.ai 👈

Setup abgeschlossen. Weiter mit der Benutzeroberfläche, Reiter für Reiter.

Checkliste für den ersten Start

Elite Intel spricht diese Warnungen beim Start der Dienste laut aus, du erfährst also von allem, was fehlt — es lohnt sich aber, das vorab zu erledigen:

Schritt Wo
Auf ein Sprachmodell verweisen Einstellungen → KI-Dienste
Journal-Ordner prüfen Einstellungen → Allgemein
Belegungsordner prüfen und fehlende Belegungen beheben Reiter Bindings
Audio kalibrieren Vega-Reiter → AUDIO KALIBRIEREN

Deinstallation (Linux)

~/.var/app/elite.intel.app/uninstall
