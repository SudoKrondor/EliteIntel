# Политика конфиденциальности EliteIntel

Данная политика объясняет, какие данные обрабатываются, как они используются и какие возможности выбора доступны пользователю.

*Последнее обновление: 14 ноября 2026 года*

## Обзор

EliteIntel — приложение с открытым исходным кодом, доступное на [GitHub](https://github.com/stone-alex/EliteIntel). Оно использует преобразование речи в текст (STT), текста в речь (TTS) и большие языковые модели (LLM) для обработки игровых данных.

Приложение может работать полностью в автономном режиме с использованием локального STT (NVIDIA Parakeet), локального LLM (LM Studio) и локального TTS (Supertonic). В этой конфигурации устройство не покидает ничего, кроме описанного ниже ежедневного подсчёта установок. При использовании облачных сервисов данные передаются, как описано ниже.

## Какие данные обрабатываются?

Никакие личные данные не собираются: ни имена, ни адреса, ни геолокация. Обрабатываются следующие типы данных:

- **API-ключи**: используются для аутентификации запросов к облачным TTS- и LLM-сервисам. Хранятся в зашифрованном виде в локальной базе данных SQLite. Передаются только в заголовках запросов к соответствующим сервисам (Google для TTS; xAI, OpenAI или Anthropic для LLM).

- **Текстовые данные (TTS)**: при использовании Google TTS текст ответа отправляется в Google. При использовании Supertonic TTS данные не покидают устройство.

- **Игровые данные (LLM)**: соответствующие игровые данные (детали миссий, рыночные данные, результаты сканирований и т. д.) отправляются в настроенный LLM. Имя Командира никогда не передаётся. ИИ обращается к вам по настроенному титулу, обращению или псевдониму.

- **Статистика установок**: раз в день приложение отправляет в Google Firebase номер своей версии и операционную систему (Windows или Linux) под случайным анонимным идентификатором, созданным для этой установки. Больше ничего не отправляется: ни имя Командира, ни игровые данные, ни настройки. Это нужно только для подсчёта активных установок, их версий и операционных систем.

- **Наборы миссий (только с вашего согласия)**: только пока обмен включён (вкладка «Командир», страница «Наборы миссий», по умолчанию выключен), приложение отправляет наборы миссий на уничтожение пиратов, которые оно узнало из журналов: названия звёздных систем, фракций и станций, число зон добычи ресурсов и день, когда набор был замечен в последний раз. Имя Командира, идентификаторы миссий, награды и всё остальное, что указывает на игрока, не отправляется. Наборы всех установок проверяются и публикуются на [elite-intel.org/data/massacre-sets.json](https://www.elite-intel.org/data/massacre-sets.json) без указания, кто их прислал.

## Как используются эти данные?

- **API-ключи**: хранятся в локальной базе данных и используются исключительно для аутентификации запросов к сторонним сервисам.

- **Аудио и текст**: отправляются в Google только для обработки TTS. Google обрабатывает данные согласно своей собственной политике конфиденциальности. Хранение данных для улучшения сервиса по умолчанию отключено при стандартном использовании API.

- **Игровые данные**: приложение не передаёт все игровые события в LLM. Оно собирает и хранит соответствующие данные локально, а затем отправляет целевые фрагменты при выдаче команды или запроса. LLM не имеет постоянного доступа к игровым данным.

## Куда передаются данные?

- **Google (TTS)**: текст отправляется в облачные сервисы Google. Регулируется [Политикой конфиденциальности Google](https://policies.google.com/privacy).

- **xAI / OpenAI / Anthropic (LLM)**: фрагменты игровых данных отправляются в настроенный облачный LLM. Регулируется соответствующими политиками конфиденциальности.

- **Google Firebase (статистика установок и наборы миссий)**: хранятся в Google Cloud Firestore под анонимным идентификатором установки. Каждая установка может записывать только свои записи, и через приложение ничего нельзя прочитать обратно. Ночная задача сопровождающих EliteIntel читает их, чтобы опубликовать общие счётчики и проверенные наборы. Как и при любом запросе в интернет, Google видит IP-адрес подключения; это регулируется [Политикой конфиденциальности Google](https://policies.google.com/privacy). EliteIntel его не хранит.

- **Никуда больше**: данные не продаются и не передаются третьим лицам. Полный исходный код доступен на [github.com/stone-alex/EliteIntel](https://github.com/stone-alex/EliteIntel).

## Права и выбор

- **Изучить код**: полный исходный код доступен на GitHub.
- **Перейти в полностью автономный режим**: используйте Parakeet, LM Studio и Supertonic. Кроме ежедневного подсчёта установок, в этой конфигурации данные не передаются.
- **Настроить провайдеров**: выберите, какой облачный LLM использовать, если вообще использовать. API-ключи управляются в локальной базе данных.
- **Удалить данные**: выключение обмена наборами миссий удаляет наборы этой установки из Firebase. Статистика установок не содержит персональных данных. Для данных, хранящихся у Google, xAI, OpenAI или Anthropic, обратитесь к их соответствующим политикам.

## Безопасность

API-ключи хранятся в зашифрованном виде в локальной базе данных и передаются только в заголовках запросов. Приложение соответствует Условиям обслуживания Elite Dangerous. Оно не читает игровую память и не использует оверлеи. Открытый исходный код позволяет сообществу проводить аудит.
