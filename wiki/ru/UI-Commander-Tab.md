# Вкладка «Командир»

<img src="images/controller.png" class="inline" height="20" alt="Командир"> Кто вы, что ваш корабль
делает за вас автоматически, о чём «Вега» сообщает без просьбы и каким голосом говорит каждый
корпус вашего флота.

![Вкладка «Командир»](images/ui-tab-commander.png)

---

## Профиль командира

**Имя командира** — заменяет ваше игровое имя для озвучивания. Пригодится, если «Вега» коверкает
ваш ник или вы просто хотите, чтобы к вам обращались иначе. Сохраняется при нажатии Enter или
щелчке вне поля.

> **Папка журнала** в V1.1 переехала в [Настройки → Общие](UI-Settings-Tab), а **папка привязок** —
> на [вкладку «Бинды»](UI-Bindings-Tab).

## Параметры корабля

Автоматизации, которые «Вега» выполняет за вас. Каждая — это обычный переключатель, записывающийся
сразу. Полезно всем, а для командиров с ограниченными возможностями — по-настоящему
освобождающе.

| Переключатель | Что делает |
|--------|--------------|
| **Увеличить скорость перед FSD-переходом** | Прибавляет тягу перед прыжком |
| **Выключать огни перед FSD-переходом** | Гасит бортовые огни перед прыжком |
| **Выключать ночное видение перед FSD-переходом** | Отключает ночное видение перед прыжком |
| **Убирать оружие перед FSD-переходом** | Убирает орудийные пилоны перед прыжком |
| **Убирать шасси перед FSD-переходом** | Поднимает шасси перед прыжком |
| **Убирать грузовой ковш перед FSD-переходом** | Убирает ковш перед прыжком |
| **Убирать шасси при взлёте** | Поднимает шасси после отрыва |
| **Закрыть интерфейс перед открытием панелей** | Закрывает открытую панель перед открытием следующей, чтобы команды панелей не сталкивались |
| **Выключать огни при выпуске SRV** | Гасит огни при выпуске SRV |
| **Отменять переход, если истребитель снаружи** | *Сейчас отключено* — ожидается исправление Frontier для ошибки, связанной с Nomad |

## Объявления

Всё, о чём «Вега» сообщает по своей инициативе. Все одиннадцать переключателей теперь в одном
месте, так что есть единственный экран, куда заглянуть, когда что-то говорит слишком много — или
слишком мало.

![Объявления](images/ui-commander-announcements.png)

| Переключатель | Что вы услышите |
|--------|---------------|
| **Объявлять открытия** | Примечательные тела, первооткрытия, биологические сигналы |
| **Объявлять прогресс маршрута** | Где вы находитесь на проложенном маршруте |
| **Объявлять радарные контакты** | Корабли, появляющиеся на сканере |
| **Объявлять добычу** | События добычи и её результаты |
| **Объявлять навигацию** | Навигационные события и прибытия |
| **Радиопередачи** | Ролевые радиопереговоры, произносимые отдельным «радийным» голосом |
| **Объявлять пункт назначения прыжка** | Какая система будет следующей |
| **Объявлять трафик пункта назначения** | Сводки движения в системе, куда вы направляетесь |
| **Объявлять потери в пункте назначения** | Недавние смерти в системе назначения |
| **Объявлять оставшиеся прыжки** | Сколько прыжков осталось на маршруте |
| **Объявлять наличие топливной звезды** | Есть ли в пункте назначения звезда для заправки |

Первые шесть можно переключать и голосом, поэтому этот экран перечитывает их всякий раз, когда вы
открываете вкладку: произнесённое `toggle all announcements` отразится здесь.

## Настройка голосов флота

По одной строке на каждый принадлежащий вам корабль. Elite Intel узнаёт состав флота из игрового
журнала; корабли вручную добавлять не нужно.

| Столбец | Примечания |
|--------|-------|
| **Корабль** | Данное вами имя корабля |
| **Модель корабля** | Тип корпуса |
| **Голос** | Щёлкните, чтобы выбрать. Смена голоса сразу проигрывает демонстрационную фразу, чтобы вы могли его оценить |
| **Характер** | `Профессиональный` · `Неформальный` · `Дружелюбный` · `Безумный` · `Без тормозов` |
| **⚙** | Открывает настройки этого корабля |

**О списке голосов.** Голоса кораблей — женские. Какие голоса появятся, зависит от движка синтеза
речи, выбранного в [Настройки → Сервисы ИИ](UI-Settings-Tab):

- **Локально (Kokoro)** — 53 голоса с подписью `Имя - акцент`. Без ключа, без загрузки, без
  настройки.
- **Облако (Google)** — с подписью `Имя - акцент · HD` или `· Standard`. В английском голоса
  различает акцент. В любом другом языке каждый голос синтезируется на этом языке, поэтому подпись
  показывает пол и уровень качества вместо вводящего в заблуждение английского акцента.

> Смена движка синтеза речи сбрасывает голос каждого корабля на значение по умолчанию нового
> движка. **Характеры кораблей сохраняются.** Приложение предупредит вас заранее.

## Настройки корабля (кнопка ⚙)

Настройки для каждого корабля отдельно, потому что добывающая Python и боевая Corvette не хотят
одинакового поведения.

![Настройки корабля](images/ui-ship-settings.png)

**Сканировать систему при входе** — выполняет сканирование открытия при прибытии в систему.
Выберите **огневую группу** (A–H) и **триггер** (1 или 2), на который установлен ваш сканер
открытий. Если ваш HUD в боевом режиме, Elite Intel переключается в режим анализа, сканирует и
возвращается обратно.

**Оповещение о материалах в мощных выбросах** — сообщает, когда сигнал мощных выбросов в системе
несёт материалы, ради которых стоит остановиться.

**Торговый профиль** — ограничения, которым следует Elite Intel, прокладывая торговый маршрут для
этого корабля. Каждое из них можно задать и голосом:
*«alter trade profile, set max stops to four»*.

| Параметр | Значение |
|---------|---------|
| **Разрешить планетарные порты** | Включать в маршруты наземные порты |
| **Разрешить запрещённые грузы** | Включать груз, незаконный где-либо на маршруте |
| **Разрешить системы с разрешениями** | Включать системы, требующие разрешения |
| **Разрешить флотские авианосцы** | Включать авианосцы игроков как рынки |
| **Разрешить системы оплота** | Включать системы-оплоты таргоидов или держав |
| **Макс. св. секунд от входа** | Насколько далеко от звезды прибытия может находиться станция |
| **Макс. остановок** | Количество отрезков маршрута |
| **Стартовый капитал** | Кредиты, которые планировщик маршрута может потратить |

О том, как проходят маршруты, см. [Торговля и прибыль](TradeRoutePlotting).
