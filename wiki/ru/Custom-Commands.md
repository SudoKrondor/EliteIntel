# Свои команды

Пользовательская команда — это макрос: список шагов — нажатия клавиш, паузы, набранный текст,
произнесённые фразы, — который выполняется, когда вы говорите одну из своих фраз. Делайте такую,
когда встроенные команды делают не то, что нужно, или когда вы раз за разом жмёте одну и ту же
последовательность клавиш.

Пользовательские команды находятся в [Действия → Пользовательские команды](UI-Actions-Tab). На этой
странице две из них собираются с нуля.

---

## Перед началом

- **Должна работать языковая модель.** Она создаёт ключ действия и сопоставляет ваши фразы.
  Сначала запустите сервисы на [вкладке «Вега»](UI-Vega-Tab).
- **Каждому используемому действию нужна клавиатурная привязка.** Elite Intel нажимает клавиши;
  действие, назначенное только на HOTAS, макрос нажать не сможет. [Вкладка «Бинды»](UI-Bindings-Tab)
  покажет, чего не хватает, а **Автоназначить отсутствующие привязки** исправит всё разом.

## Пример 1: контрмеры одной фразой

Цель: сказать *«контрмеры пошли»* и получить теплоотвод, диполи и щитовую ячейку с подтверждением
от «Веги».

### 1. Создать команду

Откройте **Действия → Пользовательские команды** и нажмите **Новый**.

### 2. Имя и фразы

- **Имя:** `Контрмеры`
- **Что вы скажете:** по одной фразе в строке (можно и через запятую):

  ```
  контрмеры пошли
  все контрмеры
  оборонительный пакет
  ```

Пишите фразы так, как действительно скажете их в горячке боя. Они должны **отличаться от встроенных
команд** — фраза, которая уже принадлежит встроенной команде (*«теплоотвод»*, *«сбрось диполи»*),
отклоняется, потому что «Вега» никогда не сможет их различить.

### 3. Создать ключ действия

Нажмите **Создать**. Языковая модель превратит ваши фразы в английский ключ `snake_case`, например
`deploy_all_countermeasures`. Вручную его ввести нельзя — он становится именем, которое видит
модель, поэтому должен быть в форме, которую модель всегда сможет повторить. Он английский, даже
если фразы русские.

### 4. Добавить шаги

Для каждого шага нажмите **Добавить шаг**. В окне выберите **Тип** и заполните то, что он требует.
Список **Привязка** подписан как экран «Управление» в игре — *Управление кораблём / Cooling / Deploy
Heatsink* — и в нём можно печатать для фильтрации (попробуйте `heat`, `srv`, `chaff`). Названия
действий там на английском.

| # | Тип | Значение | Длительность, мс |
|---|------|-------|-------------|
| 1 | Нажатие привязки | Deploy Heatsink | |
| 2 | Задержка | | 150 |
| 3 | Нажатие привязки | Use Chaff Launcher | |
| 4 | Задержка | | 150 |
| 5 | Нажатие привязки | Use Shield Cell | |
| 6 | Произнести | Контрмеры выпущены. | |

Кнопками **Изменить шаг**, **Удалить шаг** и **▲ ▼** поправьте порядок.

### 5. Сохранить и проверить

Нажмите **Сохранить**. Если что-то не так, сообщение проверки скажет, что именно, — см. *Решение
проблем* внизу страницы. Команда появится в списке.

Нажмите на её строку, затем **Запустить**, чтобы проверить без голоса. Когда всё работает, скажите:
*«Контрмеры пошли.»* Можно и набрать в игровом чате: `@Вега контрмеры пошли`.

## Пример 2: маршрут к месту, где вы часто бываете

К системе, названной вслух, «Вега» маршрут не прокладывает — названия хуже всего даются
распознаванию речи. Для места, куда вы летаете регулярно, макрос сам управляет картой галактики,
каждый раз одинаково.

![Пользовательская команда, прокладывающая маршрут к Jameson Memorial](images/ui-custom-command-navigation.png)

**Что вы скажете:** *маршрут к jameson memorial*, *отвези меня к jameson memorial*, *jameson
memorial маршрут*. Затем **Создать**.

| # | Тип | Значение | Длительность, мс | Что делает |
|---|------|-------|-------------|--------------|
| 1 | Нажатие привязки | GALAXYMAPOPEN | | Открыть карту галактики |
| 2 | Задержка | | 1000 | Дать карте загрузиться |
| 3 | Удержание привязки | CAMZOOMIN | 500 | Приблизить камеру карты |
| 4 | Нажатие привязки | UI_LEFT | | Перейти к полю поиска |
| 5 | Нажатие привязки | UI_RIGHT | | |
| 6 | Нажатие привязки | UI_SELECT | | Открыть поле поиска |
| 7 | Ввести текст | SHINRARTA DEZHRA | | Напечатать название системы |
| 8 | Нажатие клавиши | ENTER | 50 | Искать |
| 9 | Задержка | | 500 | Дождаться результата |
| 10 | Нажатие привязки | UI_RIGHT | | Перейти в панель результата |
| 11 | Удержание привязки | UI_UP | 500 | Подняться к верхней кнопке |
| 12 | Нажатие привязки | UI_SELECT | | Проложить маршрут |
| 13 | Задержка | | 3000 | Дождаться прокладки маршрута |
| 14 | Нажатие привязки | CAMYAWLEFT | | |

Для другого места выберите эту команду, нажмите **Дублировать**, поменяйте имя, фразы и систему в
шаге 7 и **Создайте** новый ключ. «Дублировать» намеренно оставляет фразы и ключ пустыми, чтобы две
команды никогда не звучали одинаково.

Запускайте такой макрос **в полёте**, с закрытой картой галактики — первый шаг открывает её, а уже
открытую закрыл бы.

## Типы шагов

| Тип | Поля | Для чего |
|------|--------|------------|
| **Нажатие привязки** | Привязка | Один раз нажать игровое действие |
| **Удержание привязки** | Привязка, Длительность, мс | Удерживать действие — тяга, камера, прокрутка меню |
| **Задержка** | Длительность, мс | Дать игре время: открывается панель, грузится карта, идёт поиск |
| **Произнести** | Текст | «Вега» что-то скажет — подтверждение или что макрос только что сделал |
| **Нажатие клавиши** | Произвольная клавиша, Модификатор, Длительность, мс | Нажать клавишу, которая не является игровой привязкой: Enter, Escape, букву. Длительность — время удержания |
| **Ввести текст** | Текст | Напечатать символы в поле с фокусом — поиск, строку чата |

**Шаги привязки лучше, чем «Нажатие клавиши».** Привязка следует за клавишей, которую реально
использует игра, поэтому макрос продолжит работать после переназначения. «Нажатие клавиши» — только
для клавиш без привязки, например Enter в текстовом поле.

**«Ввести текст» попадает туда, где фокус клавиатуры.** Сначала откройте поле — шагом привязки,
открывающим поиск, или **Нажатие клавиши: Enter** для чата связи. Иначе буквы придут в управление
кораблём как нажатия клавиш.

## Советы

- **Задержки — обычное решение.** Если шаг будто пропускается, игра была не готова. Удлините
  задержку перед ним или сдвиньте **Темп клавиатурного ввода** на [вкладке «Бинды»](UI-Bindings-Tab)
  к «Медленно» — это добавляет паузу после каждого отправленного нажатия.
- **Несколько фраз, ясный смысл.** Говорить фразу дословно не нужно; «Вега» сопоставляет по смыслу.
  Чем сильнее ваши фразы отличаются от других команд, тем надёжнее выбирается ваша.
- **Шаги «Произнести» делают макросы частью корабля** и подтверждают, что макрос действительно
  сработал.
- **Делитесь ими.** **Экспорт** записывает выбранные команды в файл; **Импорт** читает. Импорт
  заменяет текущий набор, но сначала делается резервная копия — **Восстановить из резервной копии**
  вернёт его.
- **Слушайте сообщение при запуске.** При старте сервисов «Вега» говорит, сколько пользовательских
  команд загружено и сколько не прошло проверку.

## Решение проблем

Сообщения проверки при сохранении выводятся на английском.

| Сообщение или симптом | Что делать |
|--------------------|------------|
| *Добавьте хотя бы одну фразу выше, прежде чем создавать ключ.* | Сначала напишите хотя бы одну фразу |
| *Не удалось создать ключ действия.* | Языковая модель не ответила. Проверьте индикатор ИИ на вкладке «Вега» и повторите |
| *Phrase collides with a built-in action alias* | Эта фраза уже запускает встроенную команду. Переформулируйте |
| *Phrase collides with another custom command* / *Duplicate phrase* | Две команды — или одна дважды — используют эту фразу. Измените одну |
| *Action key collides with a built-in command* / *must be unique* | Переформулируйте фразы и снова нажмите **Создать** |
| *At least one step is required* / *… is required* / *durationMs must be positive* | У шага не хватает привязки, текста, клавиши или длительности |
| Макрос работает, но что-то пропускается | Добавьте или удлините задержку перед этим шагом или замедлите темп ввода |
| «Вега» отвечает чем-то другим | Сделайте фразы более отличительными или запустите текстом: `@Вега <фраза>` |
| Шаг привязки ничего не делает | У действия нет клавиатурной привязки — см. [вкладку «Бинды»](UI-Bindings-Tab) |
