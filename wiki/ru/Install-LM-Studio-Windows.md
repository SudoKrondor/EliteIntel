## Локальный LLM — установка на Windows (LM Studio)

Запуск локального LLM обеспечивает полную конфиденциальность данных и работу офлайн. Подписка не требуется. Учитываются затраты на оборудование и электроэнергию.

Требуется [LM Studio](https://lmstudio.ai) и мощный GPU.

---

### Минимальные требования к оборудованию

Для запуска Elite Dangerous и LLM на **одном компьютере** требуется минимум **NVIDIA RTX 3060 с 12 ГБ VRAM**.

> **Подсказка:** Elite Intel можно направить на экземпляр LM Studio, работающий на **отдельном компьютере** в вашей сети. Если доступна вторая машина с мощным GPU, игровой ПК не несёт нагрузки инференса в этой конфигурации.

---

### Рекомендуемая модель

| Модель | Требуется VRAM | Примечания |
|---|---|---|
| `google/gemma-4-e4b` | ~6.3 ГБ | ✅ Требуется |

> **Почему именно она?** Она поддерживает вызов функций, необходимый компаньону. Модель, которая не умеет
> формировать вызов инструмента, не сможет управлять приложением, как бы хорошо она ни
> писала. См. [Выбрать LLM](installing-local-llms).

### Шаг 1 — Установка LM Studio

Откройте **PowerShell** и выполните:

```powershell
irm https://lmstudio.ai/install.ps1 | iex
```

Это устанавливает CLI `lms` и **llmster** — фоновый сервер LM Studio. Десктопное приложение LM Studio при этом **не** устанавливается. После установки откройте **новое** окно PowerShell для применения изменений.

Проверьте, что всё работает:

```powershell
lms --help
```

> **Примечание:** Если десктопное приложение LM Studio уже установлено, CLI `lms` может быть уже доступен. Выполните `lms --help` перед запуском установочного скрипта.

---

### Шаг 2 — Загрузка модели

Запустите фоновый сервер LM Studio, затем загрузите модель:

```powershell
lms daemon up
lms get google/gemma-4-e4b
```

Если имя не совпадает точно, `lms get` покажет найденные варианты — выберите нужный
стрелками и клавишей Enter.

[В LM Studio есть известная ошибка](https://github.com/lmstudio-ai/lmstudio-bug-tracker/issues/917). В некоторых случаях загрузка завершается с ошибкой:
```Error: No staff picks found with the specified search criteria.```

В этом случае скачайте GGUF вручную со страницы модели на HuggingFace и импортируйте его:

```powershell
lms import C:\path\to\the-model.gguf
```

Чтобы просмотреть загруженные модели:

```powershell
lms ls
```

---

### Шаг 3 — Запуск сервера

Загрузите модель и запустите сервер инференса:

```powershell
lms daemon up
lms load google/gemma-4-e4b --context-length 8192 --gpu max
lms server start
```

`lms daemon up` ничего не делает, если фоновый сервер уже запущен, поэтому его можно безопасно выполнять каждый раз.

**ПРИМЕЧАНИЕ**: Флаг `--context-length 8192` обязателен. Без него контекстное окно может быть слишком маленьким, что приведёт к усечению промпта, сбоям и галлюцинациям.

Проверьте работу, открыв браузер или другое окно PowerShell и перейдя по адресу:

```
http://localhost:1234/v1/models
```

Вы должны получить JSON-список загруженных моделей. Строка model ID в этом ответе — то, что нужно ввести в поле **Модель** в Elite Intel.

Остановить сервер:

```powershell
lms server stop
```

> ⚠️ **Важно:** Сервер LM Studio **не переживает перезагрузку**. После каждого перезапуска снова выполняйте три команды из шага 3 или воспользуйтесь одним из вариантов автозапуска ниже.

---

### Шаг 4 — (Необязательно) Автозапуск при загрузке системы

Доступны два варианта для поддержания работы сервера после перезагрузки. Если вы выполнили шаг 1, используйте **вариант A**. Вариант B подходит только тем, у кого также установлено десктопное приложение LM Studio.

#### Вариант A — Планировщик задач (десктопное приложение не нужно)

Сначала сохраните этот скрипт как `start-lmstudio.ps1` в постоянном месте (например, `C:\Scripts\`):

```powershell
$lms = "$env:USERPROFILE\.lmstudio\bin\lms.exe"
& $lms daemon up
& $lms load google/gemma-4-e4b --yes --context-length 8192 --gpu max
& $lms server start
```

Он запускает фоновый сервер, загружает модель с настройками, которые нужны Elite Intel, и запускает сервер инференса — те же три команды, что и в шаге 3.

Затем создайте задачу:

1. Нажмите **Win + R**, введите `taskschd.msc`, нажмите Enter.
2. Нажмите **Create Task** на правой панели.
3. Вкладка **General**: назовите задачу `LM Studio Server`. Флажок **«Run with highest privileges»** не устанавливайте: LM Studio не нужны права администратора.
4. Вкладка **Triggers**: нажмите New → **«At log on»** → OK.
5. Вкладка **Actions**: нажмите New → **«Start a program»**.
   - Program/script: `powershell.exe`
   - Add arguments: `-NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File "C:\Scripts\start-lmstudio.ps1"`

`-WindowStyle Hidden` не даёт окну консоли оставаться открытым при каждом входе в систему. Во время запуска скрипта окно может ненадолго мелькнуть.

#### Вариант B — Десктопное приложение

Этот вариант доступен, только если установлено десктопное приложение LM Studio. Шаг 1 его не устанавливает.

1. Откройте LM Studio и нажмите **Ctrl + ,** для открытия настроек.
2. Установите флажок **«Run LLM server on login»**.
3. Закрытие приложения сворачивает его в системный трей с продолжением работы сервера. При следующем входе в систему оно восстанавливается автоматически.

> ⚠️ **Длина контекста:** В этом варианте LM Studio загружает модель только при первом запросе и использует **стандартные** настройки модели вместо `--context-length 8192` из шага 3. Откройте стандартные настройки модели в десктопном приложении и установите **Context Length** на **8192**. Иначе контекстное окно может оказаться слишком маленьким.

---

### Шаг 5 — Настройка Elite Intel

Откройте в Elite Intel **Сервисы → Сервисы ИИ**. В разделе **Языковая модель (LLM)** выберите **LMStudio**:

- **Адрес**: `http://localhost:1234/v1/chat/completions` (значение по умолчанию). Если LM Studio находится на другой машине, замените `localhost` на IP этой машины.
- **Модель**: вставьте строку model ID из `http://localhost:1234/v1/models`. Одна модель обслуживает и команды, и запросы.

Для локального LLM ключ API не нужен.

Нажмите **Сохранить**. Elite Intel сам перезапустит языковую модель.
