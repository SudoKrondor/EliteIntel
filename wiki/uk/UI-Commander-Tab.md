# Вкладка «Командир»

<img src="images/controller.png" class="inline" height="20" alt="Командир"> Хто ви, що ваш корабель
робить за вас автоматично, про що «Вега» повідомляє без прохання і яким голосом говорить кожен
корпус вашого флоту.

![Вкладка «Командир»](images/ui-tab-commander.png)

---

## Профіль командира

**Ім'я командира** — замінює ваше ігрове ім'я для озвучення. Стане в пригоді, якщо «Вега»
перекручує ваш нік або ви просто хочете, щоб до вас зверталися інакше. Зберігається після
натискання Enter або клацання поза полем.

> **Тека журналу** у V1.1 переїхала до [Налаштування → Загальні](UI-Settings-Tab), а **тека
> прив'язок** — на [вкладку «Бінди»](UI-Bindings-Tab).

---

## Параметри корабля

Автоматизації, які «Вега» виконує за вас. Кожна — це звичайний перемикач, що записується одразу.
Корисно всім, а для командирів з обмеженими можливостями — по-справжньому визволяюче.

| Перемикач | Що робить |
|--------|--------------|
| **Автоматично збільшувати швидкість перед FSD-стрибком** | Додає тягу перед стрибком |
| **Автоматично вимикати вогні перед FSD-стрибком** | Гасить бортові вогні перед стрибком |
| **Автоматично вимикати нічне бачення перед FSD-стрибком** | Вимикає нічне бачення перед стрибком |
| **Автоматично прибирати озброєння перед FSD-стрибком** | Прибирає гарматні пілони перед стрибком |
| **Автоматично піднімати шасі перед FSD-стрибком** | Піднімає шасі перед стрибком |
| **Автоматично прибирати вантажний ківш перед FSD-стрибком** | Прибирає ківш перед стрибком |
| **Автоматично піднімати шасі під час зльоту** | Піднімає шасі після відриву |
| **Автоматично виходити з інтерфейсу перед відкриттям іншої панелі** | Закриває відкриту панель перед відкриттям наступної, щоб команди панелей не стикалися |
| **Автоматично вимикати вогні перед розгортанням SRV** | Гасить вогні під час випуску SRV |
| **Запитувати стикування винищувача перед FSD-стрибком / скасувати, якщо він випущений** | *Наразі вимкнено* — очікується виправлення від Frontier для помилки, пов'язаної з Nomad |

## Оголошення

Усе, про що «Вега» повідомляє з власної ініціативи. Усі одинадцять перемикачів тепер в одному
місці, тож є єдиний екран, куди зазирнути, коли щось говорить забагато — або замало.

![Оголошення](images/ui-commander-announcements.png)

| Перемикач | Що ви почуєте |
|--------|---------------|
| **Оголошувати відкриття** | Помітні тіла, першовідкриття, біологічні сигнали |
| **Оголошувати прогрес маршруту** | Де ви перебуваєте на прокладеному маршруті |
| **Оголошувати радарні контакти** | Кораблі, що з'являються на сканері |
| **Оголошувати видобуток** | Події видобутку та його результати |
| **Оголошувати навігацію** | Навігаційні події та прибуття |
| **Радіопередачі** | Рольові радіопереговори, вимовлені окремим «радійним» голосом |
| **Оголошувати пункт призначення стрибка** | Яка система буде наступною |
| **Оголошувати трафік пункту призначення** | Зведення руху там, куди ви прямуєте |
| **Оголошувати втрати в пункті призначення** | Нещодавні смерті в системі призначення |
| **Оголошувати залишок стрибків** | Скільки стрибків лишилося на маршруті |
| **Оголошувати наявність паливної зірки** | Чи є в пункті призначення зірка для заправки |

Перші шість можна перемикати й голосом, тому цей екран перечитує їх щоразу, коли ви відкриваєте
вкладку: вимовлене `toggle all announcements` відобразиться тут.

## Налаштування голосів флоту

По одному рядку на кожен корабель, яким ви володієте. Elite Intel дізнається склад флоту з
ігрового журналу; кораблі вручну додавати не потрібно.

| Стовпець | Примітки |
|--------|-------|
| **Корабель** | Дане вами ім'я корабля |
| **Модель корабля** | Тип корпусу |
| **Голос** | Клацніть, щоб обрати. Зміна голосу одразу програє демонстраційну фразу, щоб ви могли його оцінити |
| **Характер** | `Професійний` · `Невимушений` · `Дружній` · `Нестримний` · `Бунтівний` |
| **⚙** | Відкриває налаштування цього корабля |

**Про список голосів.** Голоси кораблів — жіночі. Які голоси з'являться, залежить від рушія
синтезу мовлення, обраного в [Налаштування → Служби ШІ](UI-Settings-Tab):

- **Локально (Kokoro)** — 53 голоси з підписом `Ім'я - акцент`. Без ключа, без завантаження, без
  налаштування.
- **Хмара (Google)** — з підписом `Ім'я - акцент · HD` або `· Standard`. В англійській голоси
  розрізняє акцент. У будь-якій іншій мові кожен голос синтезується цією мовою, тому підпис показує
  стать і рівень якості замість оманливого англійського акценту.

> Зміна рушія синтезу мовлення скидає голос кожного корабля на значення за замовчуванням нового
> рушія. **Характери кораблів зберігаються.** Застосунок попередить вас заздалегідь.

## Налаштування корабля (кнопка ⚙)

Налаштування для кожного корабля окремо, бо видобувна Python і бойова Corvette не хочуть однакової
поведінки.

![Налаштування корабля](images/ui-ship-settings.png)

**Сканувати систему при вході** — виконує сканування відкриття після прибуття в систему. Оберіть
**вогневу групу** (A–H) і **тригер** (1 або 2), на який встановлено ваш сканер відкриттів. Якщо ваш
HUD у бойовому режимі, Elite Intel перемикається в режим аналізу, сканує й повертається назад.

**Сповіщення про матеріали у потужних викидах** — повідомляє, коли сигнал потужних викидів у
системі несе матеріали, заради яких варто зупинитися.

**Торговий профіль** — обмеження, яких дотримується Elite Intel, прокладаючи торговий маршрут для
цього корабля. Кожне з них можна задати й голосом:
*«alter trade profile, set max stops to four»*.

| Параметр | Значення |
|---------|---------|
| **Дозволити планетарні порти** | Включати в маршрути наземні порти |
| **Дозволити заборонений вантаж** | Включати вантаж, незаконний десь на маршруті |
| **Дозволити системи з дозволами** | Включати системи, що потребують дозволу |
| **Дозволити флотські авіаносці** | Включати авіаносці гравців як ринки |
| **Дозволити системи фортець** | Включати системи-фортеці таргоїдів або держав |
| **Макс. св. секунд від входу** | Наскільки далеко від зорі прибуття може бути станція |
| **Макс. зупинок** | Кількість відрізків маршруту |
| **Початковий капітал** | Кредити, які планувальник маршруту може витратити |

Про те, як проходять маршрути, див. [Торгівля та прибуток](TradeRoutePlotting).
