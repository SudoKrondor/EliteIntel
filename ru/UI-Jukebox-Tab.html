Вкладка «Музыка»

Ваша собственная музыка из ваших собственных файлов — играет под «Вегой», а не поверх неё. Когда «Вега» говорит, музыка автоматически притихает и возвращается, когда она закончит, — вы не пропустите ни одного сообщения.

Ничего не нужно устанавливать, нет учётной записи, нет стримингового сервиса. Вкладка идёт сверху вниз: Музыкальная библиотека, Плейлист, Воспроизведение.

Музыкальная библиотека

Откуда берётся музыка.

  • Обзор... — выберите папку с музыкой. Elite Intel обходит её вместе с подпапками и добавляет в плейлист каждый воспроизводимый файл. Файлы добавляются в порядке папок, так что главы аудиокниги идут по порядку.
  • Пересканировать — заново просмотреть папку в поисках добавленных позже файлов.

Поддерживаемые форматы: MP3, FLAC, M4A / M4B (AAC), OGG / OGA (Vorbis) и WAV. Файлы, которые музыкальный плеер воспроизвести не может (WMA, Apple Lossless, покупки с DRM, Opus), пропускаются.

Плейлист

Плейлист — это и есть очередь: что вы видите, то и играет в этом порядке.

Столбец Значение
№ Позиция. Значок ▶ отмечает играющий трек
Название · Исполнитель · Альбом Из тегов файлов. Большая библиотека заполняется за несколько секунд
Время Длительность трека
  • Двойной щелчок по треку запускает его.
  • Перетаскивайте строки, чтобы менять порядок. Порядок сохраняется.
  • Щелчок по заголовку столбца не сортирует — это выбросило бы порядок, который вы составили вручную. Сортировка — в контекстном меню.

Файл, исчезнувший с диска, помечается как нет файла.

Контекстное меню

Пункт Что делает
Играть сейчас Запустить выбранный трек
Играть следующим Поставить выбранные треки сразу после текущего
Убрать из плейлиста Убрать из списка (файлы на диске не трогаются)
Показать в файловом менеджере Открыть папку с файлом
Копировать исполнителя и название В буфер обмена
Добавить папку... Добавить музыку из ещё одной папки
Импортировать плейлист... Добавить треки, перечисленные в плейлисте .m3u / .m3u8
Убрать отсутствующие файлы Удалить все записи, файлы которых пропали
Очистить плейлист Убрать все треки (спросит подтверждение; файлы на диске не удаляются)
Сортировать по → Названию / Исполнителю / Папке Разовая сортировка, перезаписывающая порядок плейлиста

Воспроизведение

  • Ползунок позиции — сколько трека прошло. Перетащите для перемотки; переход происходит, когда отпускаете.
  • Назад · Играть/Пауза · Стоп · Вперёд — кнопки управления. Стоп перематывает текущий трек в начало; Пауза сохраняет место.
  • Порядок — По порядку или Случайно.
  • Громкость — собственный уровень музыки. Он здесь, а не в настройках аудио, чтобы вы никогда по ошибке не приглушили «Вегу».

Место в треке запоминается между сессиями — удобно для аудиокниг, — но сам плеер никогда не начинает играть при запуске приложения.

Голосовые команды

Каждая музыкальная команда называет музыку, трек или песню, чтобы никогда не пересекаться с командами корабля.

Скажите Что происходит
«Включи музыку» / «играй музыку» Запустить или продолжить
«Поставь музыку на паузу» / «останови музыку» Пауза — «включи музыку» продолжит с того же места
«Следующий трек» / «пропусти этот трек» Следующий трек
«Предыдущий трек» Предыдущий трек
«Перезапусти плейлист» К первому треку
«Перемешай музыку» / «играй музыку вперемешку» Случайный порядок
«Включи песню Rocket Man» Найти трек по названию или исполнителю и включить. Если ничего толком не совпало, «Вега» так и скажет, а не включит не то

Эти команды работают и набранными в игровом чате — см. Все команды.
