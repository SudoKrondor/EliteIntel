Нет мощного железа? Используйте облачную LLM.

LLM (мозг ИИ)

Облачный вариант: откройте Сервисы → Сервисы ИИ → Облачная настройка, выберите провайдера в списке Провайдер, вставьте API-ключ этого провайдера, установите флажок Заблокировано и нажмите Сохранить.

Провайдера вы выбираете сами. Elite Intel не угадывает его по ключу: провайдеры слишком часто меняют формат ключей, чтобы на это можно было полагаться. Модель вы не выбираете: Elite Intel выбирает её для вашего провайдера:

Провайдер Используемая модель
Mistral (бесплатный тариф) mistral-small-2506
xAI grok-4-1-fast-non-reasoning
OpenAI gpt-5.4-mini
Gemini (Generative Language API) gemini-3.1-flash-lite-preview
Anthropic / Claude claude-haiku-4-5
DeepSeek deepseek-v4-flash

Стоимость зависит от выбранного облачного сервиса и от того, сколько вы играете.

БЕСПЛАТНЫЙ облачный вариант: Mistral

  1. Перейдите в Mistral Console
  2. Создайте аккаунт с действующим адресом электронной почты, который можно подтвердить.
  3. БАНКОВСКАЯ КАРТА НЕ НУЖНА
  4. Создайте «Организацию» (назовите как угодно, например «Elite Intel»)
  5. Сгенерируйте API-ключ.
  6. В Сервисы → Сервисы ИИ → Облачная настройка выберите провайдера Mistral, вставьте ключ, нажмите Сохранить и перезапустите сервисы на вкладке «Вега».

Вариант А: API-ключ xAI

  1. Перейдите в xAI Console.
  2. Зарегистрируйтесь или войдите в аккаунт.
  3. Перейдите в раздел API и сгенерируйте новый API-ключ.
  4. Пополните баланс аккаунта.
  5. В Сервисы → Сервисы ИИ → Облачная настройка выберите провайдера xAI (Grok), вставьте ключ в поле API-ключ, установите флажок Заблокировано и нажмите Сохранить.

Вариант Б: API-ключ OpenAI

  1. Перейдите на OpenAI Platform.
  2. Зарегистрируйтесь или войдите в аккаунт.
  3. Перейдите в раздел API и сгенерируйте новый API-ключ.
  4. В Сервисы → Сервисы ИИ → Облачная настройка выберите провайдера OpenAI, вставьте ключ в поле API-ключ, установите флажок Заблокировано и нажмите Сохранить.

Вариант В: API-ключ Anthropic/Claude

  1. Перейдите на Claude Platform.
  2. Войдите через электронную почту или Google. Примечание: вход выполняется по магической ссылке, которая приходит на почту.
  3. Перейдите в Settings → Billing и пополните баланс, прежде чем создавать ключ. Ключ, созданный на аккаунте без средств, не работает, даже если средства добавить позже.
  4. Перейдите в API Keys и создайте ключ.
  5. В Сервисы → Сервисы ИИ → Облачная настройка выберите провайдера Anthropic (Claude), вставьте ключ в поле API-ключ, установите флажок Заблокировано, нажмите Сохранить, затем запустите или перезапустите сервисы на вкладке «Вега».

Вариант Г: API-ключ Google Gemini

  1. Перейдите в Google AI Studio и войдите с аккаунтом Google.
  2. Нажмите значок ключа внизу слева.
  3. Нажмите Create API key. Если вас попросят создать проект, создайте его с любым названием.
  4. Будет запрошен платёжный аккаунт. Для этого можно использовать ваш аккаунт Google.
  5. Скопируйте ключ.
  6. В Сервисы → Сервисы ИИ → Облачная настройка выберите провайдера Google (Gemini), вставьте ключ в поле API-ключ, установите флажок Заблокировано, нажмите Сохранить, затем запустите или перезапустите сервисы на вкладке «Вега».

Получение ключа Google TTS

  1. Перейдите в Google Cloud Console.
  2. Войдите или создайте аккаунт.
  3. Создайте новый проект.
  4. Включите Cloud Text-to-Speech API.
  5. Перейдите в Credentials, создайте API-ключ и скопируйте его.
  6. Ограничьте ключ: нажмите на только что созданный ключ. На странице сведений нажмите Restrict key. Появится выпадающий список. Отметьте каждый API, который вы включили (STT и/или TTS), и нажмите Save.
  7. Вставьте ключ в Сервисы → Сервисы ИИ → Речь (TTS) → Ключ Google TTS, установите флажок Заблокировано и нажмите Сохранить.
