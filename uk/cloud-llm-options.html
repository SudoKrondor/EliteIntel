Немає потужного заліза? Використовуйте хмарну LLM.

LLM (мозок ШІ)

Хмарний варіант: відкрийте Сервіси → Сервіси ШІ → Хмарне налаштування, оберіть провайдера у списку Провайдер, вставте API-ключ цього провайдера, встановіть прапорець Заблоковано й натисніть Зберегти.

Провайдера ви обираєте самі. Elite Intel не вгадує його за ключем: провайдери надто часто змінюють формат ключів, щоб на це можна було покладатися. Модель ви не обираєте: Elite Intel обирає її для вашого провайдера:

Провайдер Модель, що використовується
Mistral (безкоштовний тариф) mistral-small-2506
xAI grok-4-1-fast-non-reasoning
OpenAI gpt-5.4-mini
Gemini (Generative Language API) gemini-3.1-flash-lite-preview
Anthropic / Claude claude-haiku-4-5
DeepSeek deepseek-v4-flash

Вартість залежить від обраного хмарного сервісу та від того, скільки ви граєте.

БЕЗКОШТОВНИЙ хмарний варіант: Mistral

  1. Перейдіть до Mistral Console
  2. Створіть акаунт із чинною адресою електронної пошти, яку можна підтвердити.
  3. БАНКІВСЬКА КАРТКА НЕ ПОТРІБНА
  4. Створіть «Організацію» (назвіть як завгодно, наприклад «Elite Intel»)
  5. Згенеруйте API-ключ.
  6. У Сервіси → Сервіси ШІ → Хмарне налаштування оберіть провайдера Mistral, вставте ключ, натисніть Зберегти й перезапустіть сервіси на вкладці «Вега».

Варіант А: API-ключ xAI

  1. Перейдіть до xAI Console.
  2. Зареєструйтеся або увійдіть в акаунт.
  3. Перейдіть до розділу API та згенеруйте новий API-ключ.
  4. Поповніть баланс акаунта.
  5. У Сервіси → Сервіси ШІ → Хмарне налаштування оберіть провайдера xAI (Grok), вставте ключ у поле API-ключ, встановіть прапорець Заблоковано й натисніть Зберегти.

Варіант Б: API-ключ OpenAI

  1. Перейдіть на OpenAI Platform.
  2. Зареєструйтеся або увійдіть в акаунт.
  3. Перейдіть до розділу API та згенеруйте новий API-ключ.
  4. У Сервіси → Сервіси ШІ → Хмарне налаштування оберіть провайдера OpenAI, вставте ключ у поле API-ключ, встановіть прапорець Заблоковано й натисніть Зберегти.

Варіант В: API-ключ Anthropic/Claude

  1. Перейдіть на Claude Platform.
  2. Увійдіть через електронну пошту або Google. Примітка: вхід виконується за магічним посиланням, яке надходить на пошту.
  3. Перейдіть до Settings → Billing і поповніть баланс, перш ніж створювати ключ. Ключ, створений на акаунті без коштів, не працює, навіть якщо кошти додати пізніше.
  4. Перейдіть до API Keys і створіть ключ.
  5. У Сервіси → Сервіси ШІ → Хмарне налаштування оберіть провайдера Anthropic (Claude), вставте ключ у поле API-ключ, встановіть прапорець Заблоковано, натисніть Зберегти, потім запустіть або перезапустіть сервіси на вкладці «Вега».

Варіант Г: API-ключ Google Gemini

  1. Перейдіть до Google AI Studio і увійдіть з акаунтом Google.
  2. Натисніть значок ключа внизу зліва.
  3. Натисніть Create API key. Якщо вас попросять створити проєкт, створіть його з будь-якою назвою.
  4. Буде запитано платіжний акаунт. Для цього можна використати ваш акаунт Google.
  5. Скопіюйте ключ.
  6. У Сервіси → Сервіси ШІ → Хмарне налаштування оберіть провайдера Google (Gemini), вставте ключ у поле API-ключ, встановіть прапорець Заблоковано, натисніть Зберегти, потім запустіть або перезапустіть служби на вкладці «Вега».

Отримання ключа Google TTS

  1. Перейдіть до Google Cloud Console.
  2. Увійдіть або створіть акаунт.
  3. Створіть новий проєкт.
  4. Увімкніть Cloud Text-to-Speech API.
  5. Перейдіть до Credentials, створіть API-ключ і скопіюйте його.
  6. Обмежте ключ: натисніть на щойно створений ключ. На сторінці відомостей натисніть Restrict key. З'явиться випадний список. Позначте кожен API, який ви увімкнули (STT та/або TTS), і натисніть Save.
  7. Вставте ключ у Сервіси → Сервіси ШІ → Мовлення (TTS) → Ключ Google TTS, встановіть прапорець Заблоковано й натисніть Зберегти.
