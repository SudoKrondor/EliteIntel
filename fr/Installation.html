Installation

Elite Intel V1.1 est la version actuelle.

Linux Windows

  1. Téléchargez le 👉programme d'installation👈.
  2. Exécutez le programme d'installation et suivez les instructions à l'écran.
  3. Configurer un modèle de langage. Elite Intel ne peut pas fonctionner sans lui. Deux options :
    • LLM local (gratuit, hors ligne) : voir le guide LLM local. Nécessite un GPU performant.
    • LLM cloud (dispose d'un palier gratuit et se configure plus facilement) : voir Options de LLM cloud pour obtenir une clé API, puis saisissez-la dans Paramètres → Services IA. Offre gratuite, sans carte bancaire : 👉 console.mistral.ai 👈

Configuration terminée. Ensuite : l'interface, onglet par onglet.

Liste de vérification au premier lancement

Elite Intel énonce ces avertissements à voix haute au démarrage des services : vous serez donc informé de tout ce qui manque — mais autant le faire d'emblée :

Étape Où
Le pointer vers un modèle de langage Paramètres → Services IA
Vérifier le dossier du journal Paramètres → Général
Vérifier le dossier des assignations et corriger les manquantes Onglet Bindings
Calibrer l'audio Onglet Vega → CALIBRER L'AUDIO

Désinstallation (Linux)

~/.var/app/elite.intel.app/uninstall
